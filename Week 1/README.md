# Week 1 - Red Teaming Fundamentals

This folder contains the documentation and practical work for Week 1 of the Cyart Red Teaming Internship. The focus of this week was to understand the fundamentals of red teaming, reconnaissance, exploitation, post-exploitation, and reporting.

---

## 📚 Theoretical Knowledge

### 1. Fundamentals of Red Teaming
- Purpose of Red Teaming and attack lifecycle
- MITRE ATT&CK framework basics

### 2. Reconnaissance and Information Gathering
- Passive and Active Reconnaissance
- Tools: Nmap, Maltego, theHarvester

### 3. Exploitation and Vulnerability Assessment
- Exploitation techniques and payload delivery
- Tools: Metasploit, OpenVAS

### 4. Post-Exploitation and Persistence
- Credential harvesting and maintaining access
- Tools: Mimikatz, Netcat, PowerShell

### 5. Reporting and Red Team Operations
- Report writing and documentation
- Rules of Engagement (RoE)

---

## 🛠️ Practical Tasks

### 1. Network Scanning
- Performed network scanning using Nmap
- Identified open ports and services
- Compared stealth scan vs aggressive scan

### 2. Vulnerability Scanning
- Used OpenVAS to scan a vulnerable VM
- Identified and prioritized vulnerabilities
- Verified exploitability using Metasploit

### 3. Exploitation Practice
- Exploited vulnerabilities using Metasploit
- Tested Samba and VSFTPD exploits
- Attempted privilege escalation

### 4. Post-Exploitation and Persistence
- Extracted credentials using Mimikatz
- Established reverse shell using Netcat
- Simulated persistence using scheduled tasks

### 5. Malware Analysis
- Used VirusTotal for file analysis
- Tested EICAR file detection
- Analyzed behavior using sandbox tools

### 6. Password Security
- Created password vault using KeePassXC
- Generated strong passwords
- Tested weak password cracking using Hydra

### 7. Security Assessment Report
- Documented findings using SANS format
- Included attack path and recommendations
- Created executive summary

### 8. Red Team Operations and Documentation
- Created attack flowchart using Draw.io
- Documented techniques in HackMD
- Built checklist using Trello

## 🎯 Key Learning Outcomes

- Understanding of red team methodology and attack lifecycle
- Hands-on experience with reconnaissance and exploitation tools
- Knowledge of post-exploitation and persistence techniques
- Ability to document and report security findings professionally
